# Jogo da Velha em Python

Jogo da velha para dois jogadores, com interface gráfica feita em Tkinter.

![Print do jogo](print.png)

## Funcionalidades
- Dois jogadores alternando X e O
- Detecção de vitória e empate
- Destaque das casas vencedoras
- Placar e botões de reiniciar

## Como rodar
1. Instale o Python (python.org)
2. Baixe o arquivo `jogo_da_velha.py`
3. No terminal, rode: `python jogo_da_velha.py`

## Tecnologias
- Python 3
- Tkinter
